# 정부 지원금 SaaS 제품 기획

## 1. 목표

사용자가 자신의 상황을 한 번 입력하면 받을 가능성이 있는 정부 지원금과 정책을 찾아주는 서비스다.

> 몰라서 놓치는 혜택을 없애는 것.

장기적으로는 정책을 대신 찾아보고, 변경을 알려주며, 신청 준비까지 돕는 정부 정책 개인 비서를 지향한다.

## 2. 해결하려는 문제

- 정책이 정부24, 복지로, 고용24, 주택도시기금, 지자체 사이트 등에 흩어져 있다.
- 정책마다 나이, 소득, 재산, 가구, 거주지 같은 조건의 표현 방식이 다르다.
- 사용자는 자신이 대상인지 알기 위해 여러 페이지를 반복해서 읽어야 한다.
- 정책 조건과 신청 기간이 바뀌어 과거 정보만 보고 기회를 놓칠 수 있다.

## 3. MVP

MVP는 AI 없이 결정 가능한 규칙 기반 서비스로 시작한다.

```text
사용자 정보 입력
  → 정책 조건 매칭
  → 신청 가능 / 추가 확인 필요 정책만 선별
  → 추천 이유와 부족한 정보 표시
  → 공식 신청 사이트 연결
```

### MVP에 포함

- 받을 가능성이 있는 정부 지원금 조회
- 정책대출 대상 가능성 조회
- 충족한 자격과 미확인 조건 설명
- 아직 답하지 않은 추가 조건 질문
- 준비 서류와 공식 신청 사이트 안내
- 정책 정보의 기준일과 출처 표시

### MVP에서 제외

- 대출 금리, 한도, LTV, DTI, DSR의 확정 계산
- 정부기관을 대신한 최종 자격 판정
- 자동 신청 또는 서류 제출
- 생성형 AI가 정책 조건을 임의로 해석하는 기능
- 모든 지자체 정책의 전수 수집

## 4. 핵심 원칙

### 추천 서비스이지 계산기가 아니다

부동산 정책에서는 “어떤 정책을 확인할 가치가 있는가”를 알려준다. 자주 변경되는 금리와 실제 대출 가능액은 공식 사이트와 취급 기관에서 확인하도록 안내한다.

### 모르는 값은 탈락으로 처리하지 않는다

사용자가 순자산이나 주택 가격을 아직 입력하지 않았다면 결과를 `신청 불가`로 만들지 않는다. `추가 확인 필요`로 표시하고 필요한 질문을 안내한다.

### 모든 결과에 근거를 보여준다

각 정책마다 다음을 함께 제공한다.

- 추천 이유
- 충족한 핵심 조건
- 확인이 필요한 조건
- 가능성이 낮은 이유
- 신청 방법
- 공식 출처
- 정책 기준 확인일

### 정책 원문과 서비스 해석을 분리한다

공식 원문, 정규화한 조건, 서비스용 설명문을 별도로 저장한다. 원문이 바뀌면 이전 버전과 비교할 수 있어야 한다.

## 5. 초기 정책 범위

초기 조사 표본은 다음 10개다.

1. 첫만남이용권
2. 부모급여
3. 아동수당
4. 국민취업지원제도
5. 신생아 특례 디딤돌대출
6. 내집마련 디딤돌대출
7. 버팀목전세자금
8. 청년전용 버팀목전세자금
9. 보금자리론
10. 신혼부부전용 전세자금

이 표본은 현금·바우처·취업지원·주택구입·전세대출처럼 서로 다른 규칙을 포함하므로 DB와 룰 엔진을 시험하기 좋다.

보조금24에는 2026-07-30 확인 기준 10,968건의 혜택·공공서비스가 등록돼 있다. 이를 처음부터 모두 정밀 조건화하지 않고 다음처럼 나눈다.

- 전체 카탈로그: 공식 API 기반 검색과 공식 링크 제공
- 부분 정규화 정책: 기본 조건으로 후보 생성
- 정밀 정책: 사람이 검수한 룰로 가능 여부와 이유 제공

MVP는 수요가 높은 전국 공통 정책 30~50개를 정밀 정책으로 제공하는 것을 1차 목표로 한다. 상세 전략은 [policy-scope.md](./policy-scope.md)를 따른다.

## 6. 사용자 경험

### 1단계: 기본 프로필

생년월일, 거주지, 혼인 상태, 가구원과 자녀, 대략적 소득 구간 등 공통 정보만 받는다.

### 2단계: 후보 생성

기본 프로필만으로 명백히 관계없는 정책을 제외한다.

### 3단계: 후보별 추가 질문

예를 들어 주거 정책 후보가 있을 때만 무주택, 순자산, 계약 상태, 보증금, 기존 대출을 질문한다.

### 4단계: 결과

```text
신청 가능성 높음  신생아 특례 디딤돌대출
- 최근 2년 내 출산 조건 충족
- 무주택 조건 충족
- 소득 조건 충족
- 확인 필요: 대상 주택 평가액과 신용 요건

신청 가능성 높음  첫만남이용권
- 출생일과 주민등록 조건 충족
- 공식 신청: 복지로 / 정부24
```

별점보다 상태 라벨을 우선 사용한다. 별점은 정확한 확률처럼 오해될 수 있기 때문이다.

## 7. 정책 수집과 최신성

우선순위는 다음과 같다.

1. 담당 부처 또는 시행기관의 상품·사업 페이지
2. 국가법령정보센터의 법령·고시
3. 복지로, 정부24, 고용24 등 공식 통합 포털
4. 지자체 공식 홈페이지와 공고
5. 공공데이터 API

블로그, 카페, 언론 기사는 정책 발견에는 사용할 수 있지만 DB 확정 근거로 사용하지 않는다.

정책마다 `마지막 확인일`, `공식 출처`, `시행 기간`, `다음 점검일`을 저장한다. 변동성이 높은 주택대출은 최소 월 1회, 안정적인 현금성 복지는 분기 1회 점검하는 방안을 제안한다.

## 8. 성공 지표 초안

- 프로필 입력 완료율
- 사용자 1명당 발견한 신청 가능 정책 수
- 결과에서 공식 신청 사이트로 이동한 비율
- `추가 확인 필요` 질문의 완료율
- 만료되거나 잘못된 공식 링크 비율
- 기준일이 지난 정책 비율
- 사용자 오류 신고 후 수정까지 걸린 시간

## 9. 장기 로드맵

```text
정부 지원금 검색
  → 개인 맞춤 정책 추천
  → 변경·마감 알림
  → 신청 준비 체크리스트
  → 정부 정책 개인 비서
```
