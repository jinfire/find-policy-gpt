# 전체 정책 질문 재설계

기준일: 2026-08-04

## 결론

결과에서 후보를 수백~수천 개 보여준 뒤 사용자가 직접 거르는 구조를 중단한다. 먼저 공통 질문과 후보별 구분 질문을 받고, 명확하게 맞지 않는 정책을 제거한 다음 하나의 추천 목록만 보여준다.

검수한 10개 정책은 초기 룰 작성용 표본일 뿐 별도의 상품군이 아니다. 화면에서는 정부24 전체 후보와 합쳐 같은 카드와 같은 상태 표현을 사용한다. 내부적으로만 조건 신뢰도와 출처를 유지한다.

## 질문 구조

### 1단계: 본인과 정확한 지역

- 생년월일
- 성별: 성별 제한 정책을 정확히 걸러내고 싶을 때 선택
- 시·도
- 시·군·구: 시군구 정책은 정확히 일치할 때만 통과
- 현재 지역 전입 시점: 거주기간 조건에 사용
- 혼인 상태와 혼인/예정일

경기도를 선택했다는 이유로 과천시·여주시 정책을 모두 보여주지 않는다. 경기도 광역 정책은 통과시키고, 시군구 정책은 입력한 시군구와 일치해야 한다.

### 2단계: 가구·자녀·소득

- 가구원 수
- 정확한 자녀 수
- 가장 어린 자녀 생년월일
- 입양한 자녀 여부
- 현재 임신 여부
- 본인·배우자 연소득

`둘째`를 선택했다고 자녀가 2명이라고 추론하지 않는다. 총 자녀 수를 별도 숫자로 받고, `3자녀 이상` 정책은 실제 자녀 수가 3명 이상일 때만 통과시킨다.

### 3단계: 직업과 소속

한 개의 포괄적인 직업 상태를 선택한다.

- 근로자
- 구직자
- 자영업·소상공인
- 학생
- 교직원
- 사립학교 교직원
- 공무원
- 군인·군무원
- 농업·축산업
- 어업
- 임업
- 무직·기타

사립학교 교직원을 선택한 경우에만 사학연금 가입 여부를 추가로 묻는다. 교직원도 아니고 사학연금 가입자도 아닌 사용자는 관련 정책에서 제외한다.

### 4단계: 해당되는 특수조건

한 질문에서 해당 항목을 모두 선택하게 한다.

- 장애인 가구원
- 한부모·조손가정
- 다문화가족
- 북한이탈주민
- 국가보훈대상자
- 질병·질환 관련 지원 필요
- 1인가구는 가구원 수로 자동 파생
- 무주택은 보유 주택 수로 자동 파생

## 판정 원칙

1. 질문의 답으로 확실히 불일치하면 결과에서 제거한다.
2. 아직 묻지 않은 조건은 통과가 아니라 `추가 확인`이다.
3. `다자녀`처럼 정책마다 기준이 다른 말은 원문의 최소 자녀 수를 추출한 경우에만 자동 제외한다.
4. `입양`, `사립학교 교직원`, `사학연금`처럼 대상이 명확한 전용 정책은 명시적 답변으로 제외한다.
5. 시도 광역 정책과 시군구 정책을 분리해 지역을 판정한다.
6. 결과는 `직접 검토 10개`와 `전체 정책 후보`로 나누지 않는다.
7. 같은 정책의 중앙·지역 접수 서비스는 후속 단계에서 묶되, 지자체 추가 혜택은 별도 정책으로 유지한다.

## 다음 고도화

고정 질문을 계속 늘리는 것이 최종 형태는 아니다. 기본 질문 뒤 남은 후보에서 가장 많이 갈리는 조건을 계산하고, 정보량이 높은 질문을 3~5개씩 추가로 묻는 동적 질문 엔진으로 확장한다. 예를 들어 후보에 입양 전용 정책이 없으면 입양 질문을 생략하고, 사학연금 정책이 남아 있을 때만 가입 여부를 묻는다.
