# 결정 0001: 원본 정보는 한 번만 질문하고 파생값을 재사용한다

- 상태: 결정
- 결정일: 2026-07-30

## 배경

정책 원문에는 나이, 청년 여부, 혼인기간, 신혼 여부, 자녀 수, 최근 출산 여부, 지역 구분, 부부합산소득처럼 서로 겹치거나 다른 값에서 계산할 수 있는 조건이 반복해서 등장한다.

이 조건을 정책별 질문으로 그대로 만들면 같은 내용을 여러 번 묻게 되고 입력 완료율과 사용자 신뢰가 낮아진다.

## 결정

사용자에게는 계산의 근거가 되는 원본 정보만 한 번 질문한다.

1. 이미 받은 정보는 다른 정책에서 다시 묻지 않는다.
2. 다른 답변으로 계산 가능한 값은 질문하지 않고 시스템에서 계산한다.
3. 정책별 표현은 공통 표준 필드에 연결한다.
4. 정책 후보가 생긴 뒤에만 해당 정책의 추가 정보를 묻는다.
5. 법적 정의의 예외 때문에 자동 계산이 불확실한 경우에만 확인 질문을 한다.
6. 확인 질문에는 질문 이유와 사용되는 정책을 표시한다.

## 예시

```text
생년월일
  → 현재 나이
  → 성년 여부
  → 청년 정책별 연령 충족 여부

자녀별 생년월일
  → 자녀 수
  → 미성년 자녀 수
  → 자녀 월령
  → 최근 2년 내 출산 여부

시군구 코드
  → 수도권 여부
  → 비수도권 여부
  → 인구감소지역 등급
```

## 결과

- 사용자가 직접 답하는 항목 수가 줄어든다.
- 여러 정책이 같은 정보를 일관되게 재사용한다.
- 계산 로직과 정책 버전 관리가 중요해진다.
- 파생값에는 평가 기준일과 사용한 정책 버전을 남겨야 한다.
- 예외적인 가족관계·주택·소득 합산 범위는 추가 질문 또는 공식 확인이 필요하다.
