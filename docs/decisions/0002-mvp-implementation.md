# ADR 0002: MVP 구현과 개인정보 범위

- 상태: 승인
- 결정일: 2026-07-30

## 결정

1. 웹은 TypeScript, React 19, vinext, Cloudflare Workers/Sites로 구현한다.
2. 정책·버전·출처·검수 이력은 D1(SQLite 호환)에 저장한다. 초기 PostgreSQL안은 배포 환경에 맞춰 D1으로 변경하되 테이블 경계와 JSON 조건 모델은 유지한다.
3. 첫 공개 범위는 공식 출처를 확인한 전국 공통 정책 10개다.
4. MVP 조회는 비회원 전용이다. 생년월일·소득·자산 등 입력값은 브라우저 메모리에서만 계산하고 서버나 브라우저 저장소에 남기지 않는다.
5. 결과는 `신청 가능성 높음`, `몇 가지만 더 확인`, `현재는 가능성 낮음`으로 표현한다. 최종 자격 판정이라는 표현은 사용하지 않는다.
6. 추천 카드에는 반드시 충족한 조건을 근거로 한 추천 이유, 미확인 질문, 공식 확인 링크, 기준일과 면책 문구를 표시한다.
7. 금리·한도·LTV·DSR은 계산하지 않고 공식 사이트로 연결한다.
8. 정책 조건은 버전이 있는 JSON 조건 트리로 관리하고, 공개 전 JSON Schema·경계값 테스트·사람 검수를 거친다.

## 질문 최소화 원칙

- 생년월일에서 만 나이와 자녀 월령을 계산한다.
- 혼인신고일에서 혼인 개월 수와 신혼 여부를 계산한다.
- 개인·배우자 소득에서 합산소득을 계산하되 필요한 값이 비면 추정하지 않고 `unknown`으로 둔다.
- 자녀 목록에서 자녀 수, 미성년 자녀 수, 막내 정보를 계산한다.
- 시도 코드에서 수도권 여부를 계산한다.
- 같은 필드와 같은 질문은 조건 분기가 여러 개여도 한 번만 보여준다.

## 후속 조건

- 로그인 프로필 저장은 별도 동의, 보관기간, 삭제 UI, 암호화 키 운영이 준비되기 전에는 활성화하지 않는다.
- 정책 30~50개 확장은 정책별 검수 책임자와 갱신 주기를 정한 뒤 진행한다.
- 법무·금융 문구와 실제 사용자 이해도는 공개 베타 전에 외부 검토한다.

## 보안 감사 메모

2026-07-30 `npm audit --omit=dev` 기준 Next가 내부에 포함한 `postcss`와 `sharp` 관련 high 경고 3건이 남아 있다. 자동 수정은 Next 14 강제 다운그레이드를 제안해 vinext/React 19 호환성을 깨뜨리므로 적용하지 않았다. 현재 앱은 사용자 CSS 입력, 이미지 업로드·최적화, Server Actions를 사용하지 않는다. Next/vinext의 호환 패치가 제공되면 우선 업데이트한다.
